# CopyMiddle（！？著著？！权）

CopyMiddle（！？著著？！权）是由 XINGJI 工作室发起的一项全新的作品共享协议。

## 什么是 CopyMiddle ？

CopyMiddle 是由 XINGJI 工作室发起的一项全新的作品共享协议，旨在解决那些不喜欢 Copyleft（著佐权）传染性但又不喜欢 Copyright（著作权）对他人修改和分发自由的限制的作品的情况。

CopyMiddle 思想将 Apache 2.0 协议作为标准，以 Apache 2.0 、BSD 协议为
代表，弘扬给予其他人修改再分发以及决定二次分发协议的自由，同时保障原作者权益得到保护与肯定的理念，力求打造一个真正完全自由的共享环境。

## CopyMiddle 的理念
- 不对他人修改和选择二次分发协议的自由进行任何限制
- 保障原作者著作权益得到保障，二次分发时必须标注原作者
- 不鄙视任何其它协议
